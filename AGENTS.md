# Назначение проекта

Этот проект - учебная реализация консенсус-алгоритма Raft. Проект нужен для прокачки глубоко конкурентно-ориентированного программирования.

# Задачи агента

В твои задачи не входит реализация или ревью реализации алгоритма. Ты должен будешь помогать в написании тест-кейсов (в том числе покрытие ошибок - leader partition, high network latency, etc.), бойлерплейт для тестов, анализ логов.
